# 上下文恢复与更新

## 读取预算与恢复顺序

1. 遵循项目指令找到入口：用户指定位置优先，否则使用已有的 `docs/context.md`；保持既有入口位置。入口缺失时，仅在用户要求建立上下文后创建最小入口，否则继续有依据的工作并说明未持久化状态。结合当前请求识别活动问题，保留仍适用的原始目标，不用旧入口覆盖用户的新指示。
2. 预算内的小型入口直接完整读取，不为普通读取计算 SHA256。既有入口过长时按 [`long-projects.md`](long-projects.md) 定向读取全局约束及当前问题所需片段并说明覆盖范围，不把完整扫描当作启动必经步骤；输出受限时缩小片段，不把截断当成读完。
3. 若总入口有主题路由，按“问题 / 何时读取 / 路径”选择当前任务的主题及必要依赖；例如通路结果依赖队列纳入决定时，补读对应决定所在片段。主题内的链接不是递归读取清单；不加载无关主题，也不把每个文件都较短当作全部加载的理由。主题较长时同样定向读取；控制本次累计读取量。
4. 核对当前问题实际依赖的输入、代码或产物。默认不读取月报；当前 context 不足以回答一个具体问题或需核对历史时，才在既定月报位置（默认总入口同级 `monthly/`）搜索问题名、日期或对象，并读取必要范围。旧日报和主题记录按同样方式兼容读取，不自动移动、删除或仅因存在而新增同类文件。待审阅记录可提供线索，不能冒充获准的决定或已核实事实。
5. 足以确定目标、约束、必要证据及下一动作时停止扩展。区分已读取、已核实和仅有入口的材料；未加载不是不存在，文件存在不等于结果已核验。

输出被截断、必要约束未核清或材料不可达时，说明缺口并继续不依赖它的工作。定向读取不宣称通读；完整扫描只用于明确请求的全面整理或核验，不因链接存在就递归加载历史。

需要分页续读或跨会话整理校验时，按 [`long-projects.md`](long-projects.md#分页与来源校验) 使用读取助手；普通短入口不计算指纹。

## 工具输出控制

- 调用前明确本次要回答的问题、对象和所需字段，先在文件或工具端筛选，再返回必要内容。大型表格返回匹配行、必要列及所需计数/统计；日志按任务、时间或错误定位片段；搜索结果先返回路径、标题和短摘要，再展开相关来源。不要先把完整表格、日志或搜索响应带入会话后再压缩。
- 大小不明时先看体量与结构；设置适合本次问题的输出范围，批量调用也控制合计返回量。小型且必要的材料可直接完整读，不机械增加预览步骤，也不把 4,000 字符的入口目标当成每次工具输出限额。
- 预览与证据核对分开：文件头或少量样本只用于了解结构。需要判断某对象是否存在、是否有反例或任务是否完成时，应检索完整的相关范围；不能将被截断、只取前 N 行或命中上限的输出解释为“没有”。匹配过多时细化条件或分批读取，保留覆盖范围和缺口。
- 返回发现及其来源路径、版本和定位信息；完整内容留在已有产物中。缺少必要证据时继续定向展开，不为省字省略有效限制或负面证据，也不为限制输出新增管理文档。

## 恢复状态核对

新会话接管或会话压缩后继续工作时，先对照总入口、当前主题及必要来源，核对有效决定、输入版本、执行状态、未完成请求和下一步条件。已在本轮核对且无变化依据的内容可复用，不要求每轮重读或全面扫描。历史摘要仅提供定位线索；当前用户指示优先，持久化记录也须检查适用性，不能仅因它已落盘就忽略新的证据。

- **已完成且核验：** 区分记录中的完成说法和本轮实际检查范围；按下一动作的需要核对产物、版本或完成依据。
- **已启动或待核验：** 启动成功、文件存在或旧摘要声称完成都不是完成证明。继续或重跑前定向核对相关任务状态、日志结尾与产物；状态不可取得时标明未知，不直接重复启动可能仍在运行的工作。
- **待办与前置条件：** 保留尚未完成的用户请求，以及有效拒绝理由、反例和重启条件；不把旧计划当作当前指令。摘要遗漏时沿现有链接补齐，摘要与来源冲突时说明差异，只继续不依赖未核清条件的工作。

自动压缩不授予写入权限，也不证明候选已获批准。核对结果先用于本次工作；只有已有写入授权或获准的变更才更新 context。恢复说明简述必要发现和缺口即可，无须另建检查表、快照或审计报告。

## 总入口与主题保存什么

沿用既有格式，无须固定模板或空章节；按恢复工作的需要安排内容：

| 内容 | 恢复时需要知道什么 |
| --- | --- |
| 目标与当前问题 | 原始研究目标、当前子问题、目前停在哪里 |
| 有效决定与边界 | 用户已决定什么，当前必须遵守哪些条件；建议与已决定事项分开 |
| 当前事实与推断 | 已核实的数据对象含义、关键数量或质量事实；暂定解释及其边界 |
| 输入与证据入口 | 当前使用的文件/对象、影响适用性的版本或处理状态、具体标题或定位词 |
| 未决问题与阻塞 | 会改变当前判断的反例、冲突、未完成核验、待用户决定事项 |
| 下一步与恢复点 | 下一动作及原因、前置条件；中断工作已完成什么、还需核对什么 |
| 必要恢复线索 | 暂停分支的问题名、记录位置和重启条件；仍影响当前工作的决定、拒绝理由和反例保留提示 |

默认在一个短入口中安排以上内容。采用主题拆分后，总入口保留项目目标、全局及跨任务约束、当前焦点/阻塞和简短的“问题 / 何时读取 / 路径”路由；主题文件承载各问题的输入版本、有效决定、观察与限制、未决事项和下一步。全局约束必须在总入口可见，不能只藏在某一主题。主题特有的决定与状态在对应文件权威维护，总入口只留导航或必要提示，不复制一份独立维护的详细状态。

链接说明“包含什么、何时要读”。相对路径以所在文档为基准，用稳定标题或关键词定位；行号需配合文件版本。跨问题约束、当前限制与阻塞放在总入口靠前位置；主题的必要依赖指向其权威位置。

context 只保留当前工作所需的状态及必要来源、版本和恢复条件。过程、过期状态和详细理由保留在月报，完整表格等引用已有产物。多个独立问题仍有较多有效状态时，可按 [`long-projects.md`](long-projects.md) 提议拆分；不因入口超长就自动建文件，也不另建专题索引或审批文档。用户明确指定记录内容时尊重其要求，同时说明体量影响。

重要条目简短注明观察/解释/用户决定、依据和适用条件，按需要保留核验时间、输入版本及重新核验条件；不强制每条填写相同字段。确认存档与证据核实是两回事，已获准保存的假设仍然是假设。

## 替换式维护与长度

每次准备写入时，根据获准范围形成候选并检查预计 Unicode 字符数；总入口以 4,000 字符为软目标，主题也保持紧凑，不以拆分规避本次读取预算：

- **保留：** 当前目标、跨任务有效约束、必要输入版本、关键观察及不确定性、阻塞和下一步。仍影响判断的拒绝理由、负面证据和限制不能只因较旧而迁出。
- **替换：** 同一问题的新状态替换旧状态，不按轮次追加流水。
- **迁出：** 已完成过程、过期状态和详细结果进入所属月报片段，或引用已存在的可靠产物；先核对去向，再移出入口。暂停问题留下必要恢复线索，不长期复制全部状态。
- **拆分：** 仍有效且可独立维护的问题状态，经批准转入主题 context；总入口保留路由和全局约束。主题同样替换旧状态、将历史归入月报，不逐轮新建文件。

将新增、替换和迁出放在同一变更清单审核；获准保存不等于永久驻留。预计超预算时先去重、替换旧状态和引用细节，不自动扩大预算或新建索引；部分确认时按实际获准子集重新检查，不顺带应用其他候选。

必要信息仍无法压缩到目标时，完整保留有效约束，说明预计/实际长度、原因，并提出围绕当前子问题缩小范围的具体方案；若由多个独立问题的有效状态造成，也可提出主题拆分供审阅。全局约束本身超额不能靠藏入主题达标。已获准且不冲突的更新可如实保留超额状态，未获准的内容只留候选。不能截断或宣称已经达标，也不能自行迁出未批准的内容。

## 冲突与过期信息

- **输入、输出与检查结果：** 核对实际产物、代码和执行依据，区分当前版本与旧版本。
- **解释与推断：** 保留假设、依据和不确定性，不因文件较新就认定解释成立。
- **人的决定：** 以用户明确作出的决定为依据，不把建议写成已批准决定。超出既有授权的研究方向、证据资格、样本取舍、主要方案或主结论选择，说明依据和取舍后交由用户判断。

有实质性备选方案时，比较输入、假设、局限和代价；无法共用输入时说明比较限制。可以暂不选择或保留多个解释；人的选择不能替代科学依据。

当前工作以用户最新指示和已核实证据为依据。输入或决定变化时，识别受影响结果及待重核范围；无法确认的说明待核实，不继续沿用已知失效的结论。需要持久化时，将当前问题、相关主题适用范围和旧条目的替换/移出纳入变更候选，经确认写入；保留仍有价值的历史依据，不只追加一条相互矛盾的说明。

全局决定改变时，在共同变更清单中标出受影响主题及待重核状态，避免它们继续宣称适用旧条件的结论有效。根入口与主题相互矛盾时核对来源和用户指示，不能按文件新旧直接选一个；未获准改写的矛盾仍须在本次恢复中说明。

## 写回与责任

总结、阶段保存及语义变更审核见 [`monthly-review.md`](monthly-review.md)。具体内容已经明确获准写入，或用户明确要求创建初始 context 时，在范围内直接执行；一般性的总结、维护或精简请求先给出变更候选。明确要求且不改语义的排版、去重或迁移可直接执行；若需取舍研究内容，先展示受影响变化。日常进展、暂停、交接和会话自动压缩不产生额外写入授权。

上述授权同样适用于主题文件和总入口路由。拆分时共同展示各文件职责、转移内容和新入口；获准后先保存并核对主题，再切换总入口的内容和路由。部分确认只应用可独立成立的获准部分；若缺少对应目标内容的授权，保留原文并说明该路由尚不能生效，不顺带建立未获准文件。

写入前核对目标条目和依据仍适用，迁出内容的可靠去向已存在或已按授权保存；仅更新获准部分。以可追溯的原始记录或产物为依据，避免从摘要继续推演未核实结论。实际修改的 context 文件用 `Updated` 标明含时区的更新时间，必要时链接到月报中具体日期和条目；历史决定时点、证据版本和被取代关系按需保留。没有实质变化时不重写。

完成后核对引用可达、表述无冲突、实际长度及恢复所需信息；说明实际更新了什么。批准删除入口文字不等于批准删除其证据文件。详细分析产物按原任务授权保存，不借产物保存自动改写 context 或另建管理文档。
