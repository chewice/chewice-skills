# 长期项目：拆分、归档与中断恢复

## 按内容拆分

使用 SKILL.md 中的入口与主题预算，不因超限而不断抬高预算。原始数据、日志和不可改写的来源不受编辑预算约束，读取时仍须分段或定向检索。

- **主题记录：** 保存一个问题的观察、解释、决定理由、反例、开放问题和证据引用。优先复用现有笔记和产物；确需新增时按内容命名，例如与入口同级的 `context-sample-design.md`。主题自身过长时按子问题或证据批次拆分，保留共同条件，不按会话次数机械切块。
- **专题索引：** 分支多到入口无法列出时，按研究主题或数据对象分组，保留状态、检索线索和路径。组索引也超预算才继续细分，不把所有历史转移到无限增长的归档文件。

以引用替代已持久化细节，移出不影响当前动作的已完成/暂停分支；仍有效的反例、限制、阻塞或未决决定保留入口提示。每份记录从入口可达，主题不复制整个项目摘要，索引不要求递归加载所有内容。

## 整理已经过长的入口

先保留来源、核对去向，再改写入口；不能只读文件头或搜索命中便宣称保留了全部状态。

1. **保留来源。** 保存完整快照及指纹，或确认等价的可恢复副本包含当前未提交内容；同时记下待改写入口的指纹。以标明历史来源且不再改写的副本为扫描源。用户禁止新增文件时复用现有可靠载体；无安全去向的有价值内容留在原处，说明未完成的整理。
2. **分段落盘。** 连续覆盖全源，包括尾部和长单行。每段有价值的内容写入对应记录，留下紧凑的“源片段 → 去向或剔除理由”核对项；跨段句子、表格、代码或论证续读到语义完整再归类，不把推断混成源内容。
3. **保存进度。** 无法当轮完成时，持久化扫描源路径/指纹、已覆盖范围、下一位置、未处理完的跨段内容和目标路径。在原入口开头链接该整理记录，并记录添加链接后的入口指纹。先保存片段去向再推进游标；下一会话核对扫描源与现行入口后续读。
4. **核对保留。** 确认目标、数据含义与版本、重要事实、证据与不确定性、决定及理由、失败/反例、放弃方案与重启条件、未完成工作和下一步均有去向。重复内容和无研究价值的流水可剔除，结论的依据不能丢；逐一核对新链接与定位片段。
5. **切换入口。** 全源覆盖后再次核对现行入口指纹，先合入整理期间新增的进展或决定，再替换为预算内入口。切换前原入口仍权威，新记录标为整理中；切换后沿当前问题及暂停/反例分支试恢复，确认无需旧聊天即可找到依据和下一步。

整理记录仅用于此次迁移。原始快照的清理由用户授权范围决定；写入成功或对话自动压缩不能代替内容覆盖和引用核对。

## 日常暂停与重新激活

暂停时保存问题、重要观察与依据、停止理由和重启条件；入口留下检索路线。重新激活时核对数据版本、有效决定和假设，再提升到活动区。无法当轮核完的结果标为待重核，保存已覆盖范围与剩余入口后分段继续。
