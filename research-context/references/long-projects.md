# 长记录的有界读取与迁移

## 普通恢复

先辨明当前问题与入口体量。短入口完整读取；既有长入口用标题、问题名、对象或关键词定位全局约束及当前任务所需内容，再读取有边界的范围。长单行按字符切片；输出截断时缩小窗口，不把文件头或搜索命中当作完整状态。

说明已覆盖和未核清的范围，尤其是可能影响当前任务的约束；没有证据不能断言未读部分无关。已获得足够依据时停止扩展；必要约束仍不清楚时，只继续不依赖它的工作，不为追求“读完整”在启动时填满会话。

如有主题路由，先读当前问题及必要依赖；月报仅在具体问题存在缺口或需要追溯时检索片段。旧日报、主题记录和索引继续可读，但不因它们存在而新建同类文件、迁移旧记录或递归读取全部历史。完整扫描仅用于用户明确要求的全面整理或核验。

## 按研究问题拆分当前状态

默认保留单个短 context。先去重、替换过期状态和引用已有产物；若仍有多个可以独立推进、各自含较多有效状态的研究问题，可提议“一个短总入口＋少量主题 context”。拆分用于隔离不同任务的读取量，历史流水仍进月报；不按字符数机械切成 `context1.md`、`context2.md`，也不按日期轮换当前状态文件。

- **位置与职责：** 沿用明确指定的位置；没有约定时，主题放在总入口同级的 `context/<问题名>.md`。例如 `docs/context.md` 对应 `docs/context/cohort-design.md`。不预建空目录/空文件；可复用适合的已有主题文件，但先区分获准状态与待审阅材料。
- **总入口：** 保留全局约束、当前焦点和紧凑路由。路由只需“问题 / 何时读取 / 路径”，例如“通路分析 / 解释富集结果或继续该分析 / context/pathway-analysis.md”。动态路由不写入 AGENTS.md，也不另建索引；AGENTS.md 保持唯一总入口和稳定加载规则。
- **主题与依赖：** 每项状态只有一个权威维护位置；共有约束留在总入口，主题保留本问题的输入版本、决定与理由、负面证据、不确定性和下一步。依赖另一问题时注明需要核对什么及其位置，不复制整份上游状态。不递归扩展目录层级；先聚焦问题和归档历史。
- **审核与切换：** 展示文件职责、逐项转移及新总入口，沿用 [`context.md`](context.md) 的授权和部分确认规则。明确授权的无损拆分直接执行；需要舍弃或改变研究含义时先审阅。先完整核对待转移部分及其依赖、保存并验证目标，再更新总入口与相对链接；切换前旧位置仍权威，新文件是候选，失败时保留原文并说明进度。局部拆分不要求扫描无关历史；全面改写则按下节完整覆盖。
- **持续维护：** 主题内也采用替换式维护，详细过程归月报，证据引用已有产物。完成或暂停时，经批准收缩为必要恢复线索、调整路由，避免活跃主题列表只增不减；不因此自动删除文件。核验时沿一个实际问题走通总入口、主题及必要依赖，并检查累计读取量，而不只看单个文件长度。

## 明确请求的全面整理

以 [`context.md`](context.md) 的替换式维护与授权边界为准，将历史放入月报或引用已有产物；仍有效的独立问题可按上述规则拆分。没有拆分需要或授权时不创建主题文件，不另建专题索引或独立审批文档。用户明确指定其他输出时遵循其范围。

1. **保护来源。** 确认已有可恢复副本覆盖当前未提交内容；没有可靠副本且本次整理需要时，保存完整快照。扫描源保持不变，记录源与待改写入口的指纹，用于跨段/跨会话识别变化。快照及迁移进度集中在项目 `temp/research-context-migration/` 下本次任务的独立子目录，不散落在入口旁。用户禁止新增文件时复用既有可靠载体；无安全去向的有价值内容留在原处。
2. **完整覆盖。** 用有界片段连续扫描至源末尾，包括尾部及长单行；跨段句子、表格或论证读到语义完整再归类。历史按可核对的发生日期进入月报；日期未知时放入整理月份，明确标为历史整理且工作日期未知，不伪造时间。已存在于原产物的细节引用即可。保留支持与反面证据、决定及理由、版本条件和未完成事项，不把推断混成源内容。
3. **保存本次进度。** 仅需要跨会话续接时维护一份临时进度记录，包含源路径/指纹、已覆盖范围、下一位置、未完跨段内容、候选状态和紧凑的“源片段 → 去向或剔除理由”；不再另建清单。先核对片段去向再推进游标，交付时说明该临时位置。下次从既有进度链接或上述临时目录定向查找对应源的记录，核对源与现行入口再续读。无需为保存进度改写未获准的 context。
4. **审阅与应用。** 全源覆盖后，展示短入口候选及新增、替换、迁出和必要拆分的共同清单，检查预计长度和各项去向。一般整理待用户确认具体变更；已明确授权的无损迁移不重复询问。替换前核对入口是否被修改，保护他人变更及新获准内容；审批已不适用的部分重新呈现，未批准的新进展留在待审阅记录。切换前原入口仍权威，候选不能冒充生效状态。
5. **恢复核验与清理。** 沿当前问题及必要暂停分支，核对目标、有效约束/拒绝、负面证据、输入版本、未决事项、重启条件及下一步能否定位。新链接和历史片段确实可达后，才算迁移完成。临时快照和进度在核验完成后按授权清理；不得删除原始证据或已有旧日报、主题文件。仍有引用依赖临时文件时，先安置其内容，不能直接清空临时目录。

完整覆盖是全面改写的要求，不是每次恢复的要求。必要信息仍超出 4,000 字符软目标时，保留并说明超额，提出收窄当前工作范围的具体方案；不强行删减，也不自动增设索引体系。

## 暂停与重新激活

用户请求保存阶段进展时，按 [`monthly-review.md`](monthly-review.md) 记录停止理由和重启条件；获准后在总入口留下问题名称、恢复位置及必要条件，详细过程归入月报。尚有有效状态的暂停主题可以保留，以重启条件作为读取触发。重新激活先核对数据版本、有效决定和假设，旧结果未重核前不当作当前结论。只读取该问题必要片段；恢复研究本身不授权写回状态。
