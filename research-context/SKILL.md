# 科研上下文

以研究问题组织当前状态、依据和下一步，使新会话可以从项目文件恢复工作。面向人的说明使用中文，专业术语、代码、路径及机器可读值保持英文。

## 共同原则

- 遵循第一性原理与 Occam's razor：明确研究问题、数据生成过程、比较对象和推断单位，选择足以改变判断的最小工作。解释力相当时优先额外假设更少的解释；问题尚未确定时保留探索状态。
- 观察、解释与用户决定分别记录，事后发现不冒充事前设计。技术检查通过不代表假设成立；支持性、null、negative、contradictory 与 inconclusive evidence 同样保留。
- 只维护一个权威 `context.md` 入口。详细依据在各自研究记录或产物中保留一份，入口提供当前状态和导航，不靠反复总结旧摘要保存历史。
- 入口默认预算为 **4,000 个 Unicode 字符**，主题记录或专题索引以 **8,000 个字符**为拆分参考。按实际工具限制调整；字符预算不代表模型 token 上限。
- 沿用项目布局和现有载体。在已授权的上下文维护中，可按需要新增最少的记录或索引，无须逐次确认；不预建目录、模板或登记体系，整理长度不构成删除原始证据的授权。
- Main Agent 统一维护入口和共享研究记录；Sub-agent 返回更新建议，或写入明确分配且不冲突的独立产物。

## 按需加载

- 恢复、更新或总结上下文：读取 [`references/context.md`](references/context.md)。
- 入口、主题或索引超预算，需要拆分归档：再读取 [`references/long-projects.md`](references/long-projects.md)。
- 委派、交接或核验：读取 [`references/delegation.md`](references/delegation.md)。
