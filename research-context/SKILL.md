# 问题驱动科研工作流

在用户已有的项目结构中，以研究问题组织工作。`context.md` 是有长度预算的当前状态与导航入口；长期依据保存在可定位的研究记录和产物中，按需读取。研究者保留方向与取舍。

## 语言

- 面向人的说明使用中文。
- 专业术语、code、paths、commands 和 machine-readable values 保持英文。

## 第一性原理与 Occam's razor

遵循第一性原理与 Occam's razor。先明确科学问题、数据生成过程、比较对象与推断单位，再选择足以改变判断的最小分析。解释力与证据相当时，优先额外假设更少的解释；复杂方法须有具体证据支持。

观察、解释与人的决定分别表达。事后发现及方法调整不冒充事前设计。成功完成分析不要求显著、支持性或符合预期的结果。null、negative、contradictory 与 inconclusive evidence 与支持性证据同样保留。

## 定位与边界

沿用项目已有结构，不自动搭建控制层、编号体系、空目录或记录模板。不要求 `QUESTIONS.md`、BRIEF/RESULT、Q-ID/A-ID、分层 Handoff 或专用平台。优先复用已有研究记录和产物；在已授权的上下文维护范围内，为保存无法继续放入入口且没有现成载体的必要信息，可创建最少的主题记录或索引。不因项目年限或规模预建层级。

只维护一个权威 `context.md` 入口，不把所有历史塞进同一文件。沿用用户指定位置；未指定时，已有的 `docs/context.md` 是约定入口。不创建互相竞争的完整项目摘要，不迁移或重命名既有入口。入口缺失且用户未要求创建时，继续有充分依据的工作并标明尚未持久化的状态；用户已要求建立上下文时，创建最小入口即可。

入口默认以 **4,000 个 Unicode 字符**为预算，主题记录或专题索引以 **8,000 个字符**为拆分参考；项目可按实际工具限制收紧或调整。这是内容预算，不是模型 token 上限。入口、索引和主题文件都可能继续增长，均须控制体量；压缩前先保存仍有价值的依据并核对可达性，不能靠截掉尾部或反复总结旧摘要维持长度。

不承担领域分析方法、环境构建、分析脚本风格或完整科研审批流程。不默认产出正式 Report；用户未明确要求时不写报告。具体分析写法可按需使用已安装的 `scripting-style`；Pixi 环境调用 `pixi-environment-builder`。缺少这些 Skill 时按上述原则继续，不阻塞分析。

已授权的上下文维护包括更新入口、保存必要的研究记录和整理导航，无需每次重复询问。不据此删除原始证据、清理用户文件、改变科研取舍，或扩展到 Git mutation 与外部写入。

`context.md` 默认记录研究状态。脚本改写、环境配置、目录迁移等工程过程由 git history、README、manifest、`docs/ref` 等各自产物承载；入口保留改变输入、产物入口、推断适用性、人的决定或中断恢复所必需的信息。用户明确要求记录的内容按其要求保存，同时控制加载量。

## 问题驱动

每项实质工作说明：当前在回答什么问题，为什么需要这一步，什么观察会改变判断，以及下一步要解决什么。

保留用户原始目标，区分研究目标、当前子问题与 Agent 提出的解释。问题尚未确定时继续澄清和探索，不强制先形成假设。重要任务开始前明确必要输入和适当检查。新证据或用户修正可以改变问题、比较方式和下一步；不要只把修正附在原有路线后面。

工作环：明确问题 → 按需读取 → 执行与核验 → 理解观察 → 更新上下文。委派、方案比较和请求人的决定只在需要时加入。任何一步都可以返回问题；不要把它变成固定 Stage Gate。

## 按需加载

- 恢复、更新或总结上下文：读取 [`references/context.md`](references/context.md)。
- 入口超预算、主题/索引持续增长或需要拆分归档：再读取 [`references/long-projects.md`](references/long-projects.md)。
- 委派、交接或核验：读取 [`references/delegation.md`](references/delegation.md)。
- 方案比较或需要人的决定：读取 [`references/decisions.md`](references/decisions.md)。

优先读取当前动作所需 reference 与 `context.md` 中的入口。先确认读取范围与是否完整，再按问题展开；入口缺失或过时时定向查找，不默认递归读取整个仓库或所有历史。可用只读工具 [`scripts/context_read.py`](scripts/context_read.py) 返回限长片段、续读位置和文件指纹，具体用法见上下文 reference。
