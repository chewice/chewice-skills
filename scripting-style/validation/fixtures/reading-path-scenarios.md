# R 阅读路径：维护场景

这些场景用于核对 R 指南的局部分组、注释位置、函数依赖和文件交接。只按修改影响选择；不要求日常分析生成评审表。示例均为虚构测量任务，字段、单位转换、筛选和汇总约定只属于题设。

## 1. 密集代码的行为保持与阅读路径

使用 [长段对照案例](../../references/r-style-comparisons.md#long-blocks-separate-responsibilities-locally) 中的两段代码。在临时项目的 `scripts/` 下执行，输入和输出分别位于相邻 `data/`、`output/`。

输入观察表按顺序为：

| sample_id | instrument_id | reading | include |
|---|---|---|---|
| S2 | B | 3 | TRUE |
| S1 | A | 4 | TRUE |
| S2 | A | 8 | TRUE |
| S3 | B | 100 | FALSE |

校准表故意按 A、B 排列，multiplier 分别为 2、10。

行为依据：输出顺序 S2、S1，次数 2、1，均值 23、8；交换校准表行序不影响结果。将所有 include 改为 FALSE 时，两份输出都保留相同列且零行；仅保留第二条时输出 S1、1、8。B 的 multiplier 改为 20 后重跑，同名结果更新为 S2=38、S1=8。

失败边界：把未选入的 S3 改为未知 instrument，或把其 reading 改为非有限值，两段都应在写出前失败；重复校准键、缺失 include 也须失败。既有结果文件存在不代表该次失败产生了有效新结果；本题不要求新增事务、删除历史输出或状态管理机制。

阅读复核：定位单位转换前后的列、全部输入检查与筛选的先后、零行输出的理由及下一文件的用途。展示、断言和保存各有具体用途；没有为每次展示生成审计表。解析或数值一致不能替代这项复核。

## 2. 有用函数及其外部依赖

请求：两个现有分析块调用同一稳定局部计算。函数当前只接收 reading，却还隐式读取 multiplier 和可变的 inclusion 标志；仅整理表达方式，保留题设选择。

预期：保留有用计算边界，说明输入、输出及重要依赖；按当前调用需要显式传入变化的设置，或保留依赖清楚的固定闭包。筛选依据在主线可见。改变一个调用的设置不得意外改变另一个调用。无需为了减少函数数量全部展开，也不创建共享包或配置框架。

## 3. 已有计算与重画交接

请求：已有费时计算产出含 sample_id、估计值和单位的 RDS，用户只要求重新绘图。已确认产物仍与当前输入和设置一致。

预期：新会话读取该产物并核对绘图所需字段后作图，不调用上游计算、不读取原始输入、不依赖遗留会话对象。保留必要标识和单位；不因图形修改重建计算。不把本题推广成所有脚本都必须拆为计算、保存、重画三个文件。

## 4. 只写代码与未决科学选择

请求：只整理一个短的输入准备脚本，保持表达式和执行约定；下一步选用什么模型尚未决定。

预期：保留简短脚本；按当前含义安排短注释和空行，保留具体待确认事项。不制造模型、结果解释、诊断图、缓存或文件拆分来填满规范。注释和可选展示不代表实际执行。

实际执行、静态复核与未覆盖范围见[验证记录](../interactive-analysis-validation.md)。这些题设不是独立盲测结果。
