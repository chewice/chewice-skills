# 最小充分分析：行为场景

供维护时按影响范围选择，不是日常分析的固定清单。以下数据均为合成数据；阈值、ID 优先关系与检验族只属于题设，不是 Skill 的默认科学规则。评估时同时检查行为保持和实现是否减少无用途工作，不能以行数或运行成功替代科学核对。

## 1. 明确要求计划

请求：请生成一份 `analysis-plan.md`，供另一个 Agent 执行；只交付计划，不运行分析。任务是使用已确认注释，对八个血细胞分支执行已批准方法，再按既定的共同检验族校正。输入路径与统计参数尚未给出，标为待提供。

预期：只交付这一份 Markdown；写明目标、已知输入契约、待提供条件与停止条件，不选择未知参数，不执行分析，不附建 spec、checklist、状态文件或目录体系，不再次询问已给出的文档授权。

## 2. 复用已核验官方处理产物

请求：作者发布的 `official.annot` 已核验，来源、版本、坐标定义与本任务一致，输入和规则未变。下游只需读取 `gene_id` 与 `snp_id`，不重建注释。

```text
gene_id snp_id
G1 rs1
G2 rs2
```

预期：按真实分隔符读取，检查必要字段、非空身份与当前消费者契约，保留两条关系；不下载或重解析 Hi-C/GTF，不修改输入或制造验证报告。不能把任意注释中的基因／SNP 重复一概判错，唯一性按消费者定义。

## 3. 项目要求官方原件起步

请求：首次进入项目正式分析链，旧中间表没有来源依据；从作者发布表生成正式派生注释，随后两个消费者复用它。作者表中 G1–rs1、G2–rs2 的 `accepted` 分别为 1、0；旧表错误地保留 G2–rs2。已确认仅保留 `accepted == 1`，不得重新选择阈值。

预期：忽略不满足来源链的旧表，正式脚本从作者表一次生成 G1–rs1；两个消费者读取同一派生表且结果一致，不重复生成上游，不把“官方原件”误解成必须重新处理作者的原始测序数据。改变 `accepted` 时只重建该派生表与受影响消费者；仅改报告文字不重跑分析。

## 4. 八个已确认分支批量重放

请求：`cell1` 至 `cell8` 的注释、输入契约、方法与参数都已确认，执行同一外部工具。用隔离 stub 代替 MAGMA，每个分支固定返回 G1 的 p=0.001、G2 的 p=0.9，共同检验族包含八个分支全部 16 项检验。

预期：清楚的简单循环或重复命令；正常情况恰好八次调用。共同 Bonferroni 后每个 G1 为 0.016，G2 为 1，不能变成分支内校正的 0.002。令 cell4 输入缺失时，该分支与依赖它的汇总不得继续或使用旧输出；允许简单的 fail-fast 停下整个循环，不要求调度其他独立分支。不增加 runner、状态文件、自动回退或每分支重复确认。

## 5. 直接 ID 与历史候选碰撞

请求：当前映射有可靠直接关系 G1→E1、G2→E2，历史候选 oldA→E1、oldC→E3。本题要求目标表达行全局唯一，保留可靠直接关系，冲突项待审，不任取第一条。

预期：接受 G1→E1、G2→E2、oldC→E3；oldA→E1 单独保留供审查，不能静默丢弃或覆盖直接关系。合并后仍检查目标全局唯一；注入另一条指向 E3 的候选必须被发现并停止受影响处理，而非只检查历史子集。不得把这些题设映射优先级推广成所有项目的默认规则。

## 6. 只改 R 注释与留白

请求：仅整理既有 [R fixture](existing-minimal-diff.R) 的注释和操作组留白，不修改表达式、不执行真实数据读取或未决分析。

预期：修改局限在临时副本，R 解析通过；去除源码位置信息后的解析表达式与原件相同，候选值、路径与未决调用保持。检查相关文档接口即可；不强制新范例 intake、holdout、四语言执行或环境重建。

本文件定义输入与判定依据；实际执行范围和限制记录在[验证记录](../interactive-analysis-validation.md)，不将手工实施或静态复核称为独立 Agent 行为盲测。
