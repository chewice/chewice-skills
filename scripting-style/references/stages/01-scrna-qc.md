# 01 — scRNA-seq QC

## 任务主线

1. 明确计数矩阵、样本 metadata 和参考资源。
2. 检查样本、barcode、feature 与矩阵维度。
3. 逐项计算与当前数据相关的 QC 指标。
4. 查看每个指标的分布、样本差异和异常值。
5. 根据证据提出过滤阈值或保留范围。
6. 保存 QC 表、诊断图、metadata 和必要矩阵。

## 保持可见的决定

- 使用哪些 QC 指标及其生物学/技术理由；
- 阈值是预设、数据驱动还是待人工确认；
- 是否按样本使用不同阈值；
- 过滤前后细胞与 feature 数量；
- 计数工具和输出格式的差异。

## 函数与语言

- R 中按指标线性展开，检查紧邻计算。
- Bash 中把输入、输出、参考资源和命令顺序显式写出。
- 多个样本块可以少量重复；只有样本数量大且命令完全同构时才使用简单循环。
- 不为 QC 指标建立统一 class 或跨项目配置层。

## 典型产物

QC metadata、指标汇总表、分布/散点诊断图、过滤前后统计、下游可读取对象。

## 不应泛化

不得复制范例中的 cellranger/STARsolo 参数、参考路径、QC cutoff 或样本名。
