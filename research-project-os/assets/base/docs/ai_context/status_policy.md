# Status Policy

为 project、task、analysis、question、observation、hypothesis、evidence 和
decision objects 使用相互独立的 state system。详见已安装 Skill 的
`references/governance.md`。

Execution 不代表 validation。Agent 可以提出 `stable` analysis 和 `approved`
decision，但只有 human review 可以授予这些状态。

`explore`、`archive` 和 `pipeline` 是 artifact stage，不是 analysis 或 evidence
status。进入 archive 只表示人已审核该冻结快照，不能自动提升 scientific claim。
