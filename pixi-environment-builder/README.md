# pixi-environment-builder

Private source repository for the `pixi-environment-builder` Codex Skill.

The distributable Skill is located at `skills/pixi-environment-builder/`.
It covers Pixi environment design, migration, diagnostics, and TUNA mirror
conversion. New workspaces include a default `init` task and the bundled
`setup-vscode.sh` template for repository-local VS Code configuration.
