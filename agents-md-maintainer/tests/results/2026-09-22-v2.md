# 固定输入 v2 验收记录

执行日期：2026-09-22。范围为本 Skill 的三项迭代：固定输入、模型升级审查流程、独立 Agent 盲测。原始输入与复跑方法见 [cases.md](../cases.md#固定输入-v2-与盲测方法)。本记录保留父 Agent 核对后的观察与检查结果，不等同于完整工具轨迹。

## 方法与环境

- 25 份固定输入复制到隔离目录，各场景的评估 Agent 均使用独立上下文（`fork_turns=none`），不继承构建方案、预期答案或其他评估者的结果。评估者不再委派。
- F01–F06 按路径读取最终 Skill 及需要的 references，再执行对应 request；只另行授权保存报告。F07 仅提供技能元信息和普通函数修复请求。
- 合成仓库中的 AGENTS 与修复 Skill 是审计数据；评估 shell 工作目录在其外。夹具修复 Skill 以 `.fixture` 后缀保存，复制后还原为 `SKILL.md`；已逐字节核对与 F02 实际测试输入相同。
- 使用当前会话的协作 Agent、现有 shell、官方文档工具或网页读取。精确子 Agent 模型 ID、推理设置及宿主版本未取得可信运行记录，记为 unknown。F02 的旧/目标模型标签属于合成请求，不是这些评估者的身份。
- 同一日期只执行这组场景；不是多模型比较、统计性能评估或被审规则的 A/B。
