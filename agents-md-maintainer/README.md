# agents-md-maintainer

审查已有 `AGENTS.md` 中的重复要求、项目变化、指令冲突及模型升级后的适用性，输出中文建议和最小 diff。默认只审计，获准后才应用修改；保留数据保护、科研决策和必要验收边界，允许零修改。

## 维护依据

- **官方资料**：模型迭代判断仅采用 OpenAI 针对相关模型发布的指南，核实模型、产品范围及日期；Codex 产品文档用于加载与配置机制。见[来源记录](references/sources.md)。这些是参考依据，不代表官方认证。
- **项目事实**：代码、配置、实际测试、历史失败和用户约定决定建议是否适用；官方指南不能单独证明某条规则可以删除。见[审查指南](references/review-guide.md)。
- **实际验收**：已有[固定案例与独立 Agent 测试](tests/cases.md)、[原生名称调用及项目实验](tests/results/2026-09-22-native.md)。标题任务有单组 A/B；修复任务因输入漂移仅属配对观察，未证明跨模型效果或稳定成本收益。

修改本 Skill 时，先提出有证据的候选，经用户批准后应用，并记录验证范围；实际启动输入与委派证据的统计范围分别核对。

## 环境依赖

| 场景 | 需要什么 |
| --- | --- |
| 日常审计（必需） | 能读取本地文件并执行 Skill 指令的 Codex/Agent；本 Skill 的 SKILL.md、references、目标 AGENTS.md 及相关项目材料的读取权限 |
| 核实最新官方指南 | 可联网的网页检索或官方文档工具；不限定 MCP 插件。离线仍可审查本地内容，但标明官方更新未核实 |
| 保存报告或应用修改 | 对目标位置的写入权限及用户授权 |
| 维护者格式校验（可选） | 现有 skill-creator 的 `quick_validate.py`、Python 3 和 PyYAML；不属于日常运行依赖 |

本 Skill 为纯指令实现，无额外运行脚本或软件包依赖；不要求 Node.js、Pixi、特定模型版本或其他科研 Skill。项目行为实验所需环境由具体项目决定。

## 使用

宿主已发现本 Skill 时：

```text
$agents-md-maintainer 审查当前项目的 AGENTS.md，只给建议，不修改文件。
```

未被发现时，可指定本目录 [SKILL.md](SKILL.md) 的绝对路径请 Agent 读取使用。模型升级审查时补充目标模型；批准应用时指定报告和建议编号。
