# 科学问题框架

初始框架依据 Notion 页面[《提出生物医学科学问题：从现象到可检验问题》](https://app.notion.com/p/3b4b89d080ff81cbb66add239adf07b6)提炼；当前版本加入研究者主导的探索与修订。框架用于帮助理解和形成问题，真实科学主张仍需检索支持。

## 1. 从第一性原理拆开困惑

先围绕当前疑问厘清：

- **观察**：具体发生了什么，来自用户经验、数据还是已检索文献？观察有多稳定？
- **概念与测量**：使用的词指什么，测量实际捕捉了什么？
- **解释与假设**：从观察走到解释需要哪些前提？哪些已支持，哪些待核实？
- **未知与意义**：真正不理解哪一段，弄清它会增加什么认识？

用研究者能修订的语言表达，不要求每轮填写全部字段。既有知识提供起点，关键假设仍可追问。

区分 `研究主题、知识缺口、科学问题、科学假设、目标估计量、研究设计与方法`，按问题成熟程度使用。发现过程可以往返：异常数据、测量困难或文献冲突都可能改变问题。从探索生成的假设注明其来源，后续检验说明数据是否独立；不追写成预先提出的验证性假设。

## 2. 用知识张力展开可能性

按需借助以下角度，不必逐项生成候选：

1. **现象与理论矛盾**：原有解释在哪些条件下不足？
2. **同一现象有多个解释**：组成、状态、异质性或测量过程分别能解释什么？
3. **平均值掩盖差异**：分布、亚群、阶段或状态是什么样？
4. **关系的时间、方向或机制未知**：哪种时序或干预观察能使理解前进一步？
5. **适用边界未知**：现象在其他人群、组织、物种、平台或阶段是否仍出现？
6. **真实决策仍不确定**：还需要什么信息才能改善当前选择？

“尚未做过”可以触发查问，继续解释值得了解的具体未知。先描述一个尚不清楚的现象也有价值，无需立即承诺机制或应用。

## 3. 用奥卡姆剃刀比较解释与路径

比较解释前，先明确它们需要解释的同一组关键观察。在解释能力和证据相容性相当时，优先额外假设较少的解释；有尚未解释的观察或可检验的新预测时，再增加复杂性。

例如，组织的总体表达变化可以先考察细胞组成与细胞内状态各能解释多少。若组成变化已能解释现有观察，可先检验这一解释；若同类细胞内部仍存在稳定变化，则保留状态改变的可能。不能仅凭组成解释较简单就宣布它成立，也不必预先拼出一条多环节机制。

对解释性问题：列出当前确有依据的模型，比较预测差异，寻找区分它们的最小观察或实验。尚无合理替代模型时，可先探索，不凑模型数量。

对描述性问题：明确要认识的现象或分布，先考虑可靠测量、重复性及测量过程能否产生该现象。简单模型若遗漏关键异质性，应增加必要结构。

选择下一步时，说明它减少什么不确定性。最少的工具或最低的成本本身不构成充分理由；独立重复、必要对照和识别条件不能因简化而删除。

## 4. 按阶段展开问题

探索中的表述可以是：

> 我们注意到【现象】，目前不清楚【具体困惑】；先了解【下一项信息】，有助于判断是否继续追问【方向】。

准备投入研究时，再按主要问题类型明确适用部件：对象与场景、暴露或干预、比较、结果、时间、层级、目标估计量、主要替代解释和测量边界。描述性研究可用分布、比例或变化模式作为目标量，不硬套暴露—干预句式。

| 主要目标 | 问题表达 | 设计时关注 |
| --- | --- | --- |
| 描述 | 发生了什么，如何分布或变化 | 对象、抽样、测量质量、重复性和不确定性 |
| 关联 | 哪些因素共同变化 | 比较、混杂、单位与时间；关系不自动说明方向 |
| 预测 | 能否预测未见个体 | 目标人群、数据泄漏、校准、判别及适用范围 |
| 因果 | 改变暴露是否改变结局 | 干预或明确的识别假设 |
| 机制 | 现象通过什么过程产生 | 模型的区分性预测，按需安排时序、扰动或救援 |
| 转化 | 能否改善实际决策或结局 | 具体使用者、增量价值、净获益及实施条件 |

探索期可以在目标之间比较；设计时明确当前主要目标和可支持的结论。不同目标可以形成后续问题，不要求一项研究同时完成全部层级。

定义 estimand 时，可按问题使用效应差异或描述目标：

> 在【目标人群与时间】中，需要估计【比较效应/比例/分布/变化模式】，独立单位为【单位】，必要条件为【条件】，关注【不确定性】。

单细胞研究特别注意供体与细胞层级：疾病分组通常在供体层面，同一供体的细胞不能当作独立生物学重复。聚类标签及整合表示应结合测量与生物学证据理解。

## 5. 探索检查与投入检查

探索时只需推进：困惑是否变清楚、为什么仍有吸引力、下一步能学到什么。对不成熟项说明当前状态：

| 状态 | 合适的下一步 |
| --- | --- |
| 尚未想清楚 | 回到现象、概念或研究者的关注点 |
| 尚未核实 | 定向检索、检查数据或小规模观察 |
| 已知当前路径不可行 | 说明具体冲突及替代路径，由研究者决定调整或搁置 |

准备投入时，按研究类型检查：目标与测量清楚；独立单位和抽样合理；推断与设计匹配；所需资源可达；主要偏差有处理路径；结果能增进认识或指导行动。假设检验说明哪些结果削弱假设；描述研究说明目标量、测量质量和重复性，不强求 falsifier 或竞争机制。

尚无证据支持的承重前提可以先作为小规模探索的对象。研究者可选择承担已说明的探索风险；资源、伦理和证据事实不能以偏好代替。缺少临床转化链路不影响基础问题作为探索候选。

## 6. 比较与人的选择

选择对当前取舍有用的维度：兴趣匹配、预期知识增量、前提支持、解释区分或描述能力、可行性、下一步信息价值，以及按需考虑的竞争窗口与转化价值。

用具体理由比较；需要标签时可用 `高 / 中 / 低 / 未知 / 不适用`，无需填满所有维度。不用乘法公式或主观总分将某一维不足自动变成问题无价值。

AI 推荐应说明取舍与依赖的前提。人在理解问题、保留候选、改变方向和准备投入时作出决定。允许研究者提出新方向或全部否定候选；既有决定无需重复确认，相关前提变化时再提出重议。

## 7. 保留探索轨迹

总结保留最初困惑、改变理解的观察或反馈、目前有吸引力的问题、人的选择及下一步。事实、暂定解释和未核实线索清楚区分。只呈现影响当前判断的限制，并说明它带来的具体追问；不在每段重复防御性措辞。

例如，研究者将“为什么均值升高”纠正为“为什么只有部分样本升高”后，应将问题改为差异的分布与来源，解释均值候选为何被搁置，并围绕研究者关心的异质性安排下一步。不能只在偏好栏记下纠正而继续原来的机制路线。
