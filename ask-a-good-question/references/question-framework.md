# 科学问题框架

初始框架依据 Notion 页面[《提出生物医学科学问题：从现象到可检验问题》](https://app.notion.com/p/3b4b89d080ff81cbb66add239adf07b6)提炼。用于形成和修订问题，真实科学主张仍需检索支持。

## 1. 拆开当前困惑

- **观察**：发生了什么，来自用户经验、数据还是文献，有多稳定？
- **概念与测量**：所用术语指什么，测量实际捕捉了什么？
- **解释与假设**：从观察到解释需要哪些前提，哪些尚待核实？
- **未知与意义**：不理解哪一段，弄清它能增进什么认识？

区分研究主题、知识缺口、问题、假设、目标量与方法。只有方向时先找具体未知；数据异常或测量困难也能生成问题。探索产生的假设注明来源，不追写成事前设定的验证性假设。

## 2. 从已有认识找到值得追问的未知

领域背景、发展、共识和前沿的检索与判定见 [证据编排](evidence-orchestration.md)。根据当前线索选择有用的角度，不必逐项生成候选：

1. **现象与理论矛盾**：原有解释在哪些条件下不足？
2. **多个解释并存**：组成、状态、异质性或测量过程分别能解释什么？
3. **平均值掩盖差异**：分布、亚群、阶段或状态是什么样？
4. **时间、方向或机制未知**：哪种时序或干预观察能推进理解？
5. **适用边界未知**：在其他人群、组织、物种、平台或阶段是否仍出现？
6. **实际决策不确定**：还需要什么信息才能改善选择？

“尚未做过”、换场景或使用新技术可以提示线索，候选仍需说明具体未知和知识增量。先可靠地描述现象也有价值，不必承诺机制或临床应用。问题表述和记录格式使用 Brief，不要求探索初期填全字段。

## 3. 比较解释，选择最小核实步骤

解释性问题先明确模型共同面对的关键观察，核对各自所需的假设，再找预测不同之处。没有合理替代模型时可以先探索，不凑模型数量；新增观察支持必要复杂性时重新比较。

例如，组织总体表达变化可先考察细胞组成与细胞内状态各能解释多少。若同类细胞内部仍有稳定变化，组成解释可能不足；不能只因组成解释较简单就宣布它成立。

描述性问题先检查现象能否稳定测得、如何分布，以及测量过程能否产生该现象。每项核实说明它减少什么不确定性，以及支持、阴性或无法区分的结果分别会怎样改变下一步。简化时保留可靠测量、独立重复和识别所必需的条件。

## 4. 按研究目标细化设计

准备投入时明确对象、场景、时间、独立单位、目标量及适用的比较与测量边界。目标量可以是效应，也可以是比例、分布或变化模式；描述性研究无需硬套暴露—干预句式。

| 主要目标 | 问题表达 | 设计时关注 |
| --- | --- | --- |
| 描述 | 发生了什么，如何分布或变化 | 抽样、测量质量、重复性和不确定性 |
| 关联 | 哪些因素共同变化 | 比较、混杂、单位与时间；关系不自动说明方向 |
| 预测 | 能否预测未见个体 | 目标人群、数据泄漏、校准、判别及适用范围 |
| 因果 | 改变暴露是否改变结局 | 干预或明确的识别假设 |
| 机制 | 现象通过什么过程产生 | 区分性预测，按需安排时序、扰动或救援 |
| 转化 | 能否改善实际决策或结局 | 使用者、增量价值、净获益及实施条件 |

不同目标可形成后续问题，一项研究不必完成全部层级。单细胞研究需区分供体与细胞：疾病分组通常在供体层面，同一供体的细胞不能当作独立生物学重复。聚类标签和整合表示应结合测量与生物学依据解释。

## 5. 依据成熟程度判断下一步

| 当前情况 | 下一步 |
| --- | --- |
| 尚未想清楚 | 回到现象、概念或研究者关注点 |
| 尚未核实 | 定向检索、检查数据或小规模观察 |
| 已知路径不可行 | 说明资源或设计冲突与替代路径，由研究者决定调整或搁置 |

准备投入时检查目标与测量、独立单位与抽样、推断与设计、资源可达性及主要偏差的处理路径。假设检验需说明哪些结果能削弱假设；描述研究关注描述目标、测量与重复性，不强求竞争机制。

比较候选时只用当前取舍需要的维度：兴趣、知识增量、前提支持、解释区分或描述能力、可行性与下一步信息价值。转化是目标时，再检查发现如何连接可操作对象、使用者与决策、预期获益及实施条件；基础问题无需补写临床故事。未知与不适用如实保留，具体路径不可行仍可保留原始困惑。
