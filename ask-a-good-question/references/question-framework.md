# 科学问题框架

本框架依据 Notion 页面[《提出生物医学科学问题：从现象到可检验问题》](https://app.notion.com/p/3b4b89d080ff81cbb66add239adf07b6)提炼。它用于结构化与否决问题，不替代实时文献检索。

## 1. 保持六个层级分离

按以下顺序推进，不要倒置：

`研究主题 → 知识缺口 → 科学问题 → 可证伪假设 → 目标估计量 → 研究设计与方法`

- 研究主题：关注的领域，不是可回答的问题。
- 知识缺口：现有证据不能解释或不能区分的部分。
- 科学问题：可由证据回答的明确疑问。
- 科学假设：问题的可证伪预期答案。
- 目标估计量：需要从数据估计的具体量。
- 分析任务：用于估计目标量的方法。

“已有数据/方法 → 跑结果 → 事后定义问题”违反该顺序。

## 2. 从六类知识张力生成候选

1. **现象与理论矛盾**：寻找解释 A 与 B 的边界条件。
2. **同一现象有多个解释**：区分组成、状态、网络、异质性、混杂或测量模型。
3. **平均效应掩盖异质性**：定位可重复的亚群、阶段或状态。
4. **关联缺少时间、方向或机制**：用时序、干预或中介证据区分模型。
5. **适用边界未知**：检验人群、组织、物种、平台或阶段的泛化。
6. **真实决策仍不确定**：检验信息在现有路径之外是否增加净决策价值。

“尚未做过”不是独立的知识张力；还需说明为何未解决点重要且可验证。

## 3. 写清八个必要部件

1. Population/System：患者、动物、组织、细胞、分子系统。
2. Exposure/Intervention：疾病、治疗、基因型、环境、时间或实验操作。
3. Comparator：对照、基线、其他治疗、脑区或剂量。
4. Outcome：临床终点、比例、分子程序、网络或功能表型。
5. Time：横断面、治疗前后、随访、发育或病程阶段。
6. Level：个体、器官、组织、细胞类型、状态、分子或网络。
7. Estimand：效应、参照、独立单位、调整条件和不确定性。
8. Boundary/Alternatives：混杂、选择、误差、反向因果与泛化范围。

通用句式：

> 在【对象与场景】中，【暴露/干预】相对于【比较】，是否改变【明确结果】；目标效应在【时间与层级】如何定义，是否独立于【主要替代解释】，并能否在【验证边界】下重复？

竞争模型句式：

> 观察到的【现象】主要符合【模型 A】、【模型 B】还是【模型 C】？哪些观测能够区分它们？

## 4. 只选择一个主要推断层级

| 层级 | 核心问题 | 必要证据提醒 |
| --- | --- | --- |
| 描述 | 发生了什么 | 不能说明变量关系 |
| 关联 | 哪些因素共同变化 | 不能自动说明方向或因果 |
| 预测 | 能否预测未见个体 | 需要校准、判别与外部验证；性能不等于机制 |
| 因果 | 改变暴露是否改变结局 | 需要随机化或明确识别假设 |
| 机制 | 效应通过什么过程产生 | 需要时序、扰动、救援与正交证据 |
| 转化 | 能否改善决策或结局 | 需要增量价值、净获益与实施证据 |

纵向观察增强时间顺序但仍有时变混杂；随机干预估计干预效应但不自动揭示机制；体外或动物扰动支持局部机制但不能自动外推到人。

## 5. 定义 estimand 与独立单位

使用句式：

> 在【目标人群】中，【A】相对于【B】对【Y】的【平均差/风险差/比值/变化率】，统计单位为【单位】，时间窗口为【时间】，在【协变量】条件下估计。

特别注意单细胞研究：疾病分组通常发生在供体层面；同一供体的细胞不是独立生物学重复；聚类标签不是天然稳定实体；整合用于表示对齐，不等于统计证据合并。

## 6. 优先区分竞争性模型

1. 列出至少两个都能解释现象的模型。
2. 为每个模型写出可观察预测。
3. 找出预测不一致的部分。
4. 选择最能放大这些差异的测量与设计。
5. 预先规定哪些结果支持、削弱或无法区分各模型。

常见模型包括组成、状态、网络、异质性、混杂与测量误差。问题价值来自减少不确定性与区分解释，而非显著结果数量。

## 7. 评价意义而非热度

用四个问题检查科学意义：

1. 回答后减少哪一种具体不确定性？
2. 能区分哪些竞争性解释？
3. 会改变哪项理论、实验或临床决定？
4. 当前设计真的能支持所用措辞吗？

近似关系可写为：

`科学价值 ≈ 不确定性减少 × 解释区分度 × 决策影响 × 可验证性`

任何一项接近零，都需要重构问题。

## 8. 硬门与快速否决

进入正式文献审计前，检查：

- 主要概念可操作化；
- 对象、比较、结局和时间明确；
- 独立单位与分组层级一致；
- 主要推断层级唯一且与设计匹配；
- 至少一种结果会否定假设；
- 主要替代解释与测量偏差已列出；
- estimand 可用一句话写清；
- 最小充分设计能在资源与伦理边界内完成；
- 关注效应量与不确定性，不只看 P 值；
- 有敏感性分析或外部重复路径；
- 回答后会改变行动。

遇到以下任一情况，返回重构：只能写成“看看有什么”；结果不可测；统计单位错误；横断面设计承诺因果或机制；没有 falsifier；只追显著性；方法决定全部问题；回答后不改变认识或行动。

## 9. 候选比较口径

对每个维度使用 `高 / 中 / 低 / 未知`，禁止只给标签：

- **偏好匹配**：Human 是否愿意长期投入，而非 Agent 猜测。
- **缺口与撞车**：缺口能否明确到竞争解释；检索范围内最近邻有多近。
- **前提支持**：承重前提是否有直接、部分或间接真实证据。
- **模型区分**：不同结果能否实质改变解释。
- **可行性**：关键样本、测量、独立重复、时间、预算、伦理是否可达。
- **实验信息增益**：即使阴性，是否仍能排除重要模型。
- **转化链路**：是否存在具体使用者、决策、增量价值与实施条件。
- **前景耐久性**：价值是否依赖短期热词；竞争窗口和后续研究空间是否合理。

把关键未知单列，不用主观总分掩盖它。
