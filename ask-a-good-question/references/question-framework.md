# 科学问题框架

初始框架依据 Notion 页面[《提出生物医学科学问题：从现象到可检验问题》](https://app.notion.com/p/3b4b89d080ff81cbb66add239adf07b6)提炼；补充思想来源与采用边界见 [README](../README.md)。真实科学主张仍需检索支持。

## 人的偏好与当前目标

先辨明本轮选择的是一次核实、一个项目还是长期方向，沿用相应的时间与投入范围，在同一尺度上比较候选。切入口可行不代表整个研究可行；当前入口受阻也不说明长期问题不值得追问。尺度已清楚时直接推进，不新增问卷或重复确认。

沿用研究者已表达的关注、投入意愿和本轮目标。需要比较候选而偏好尚不明确时，提出与其情境相符的建议供选择：

| 情境 | 可提出的取舍建议 |
| --- | --- |
| 研究生入门、首次独立研究 | 偏重 feasibility，选择范围适当、能获得可解释结果并学习研究方法的切入口 |
| 已有基础、博士后或独立课题准备 | 同时争取 interest 与 feasibility，结合时间、独立性和发展目标比较具体取舍 |
| PI 规划长期方向 | 偏重值得持续追问的大问题，将其拆成近期可推进的小项目 |

这是讨论起点，不是按身份赋权。实际目标与人的明确偏好优先；身份未知但取舍已清楚时不必追问身份。Agent 用证据说明可能的知识增量、依据与不确定性；研究者判断这种增量是否值得自己或团队投入。新颖性、期刊声望和热度不能替代人的兴趣。

Agent 核实数据、样本、方法和协作等资源条件，解释它们能支持什么判断；研究者决定是否争取缺失资源，以及愿意承担的时间、失败风险和机会成本。区分已核实条件、待核实条件、Agent 的可行性判断与人的投入意愿。多人意见不一致时列出分歧，不替他们合成权重；沿用已有选择，只在出现会改变方向或关键投入的新取舍时请人决定。

### 复用既有经验（按需）

优先读取与当前困惑直接相关的问题记录、文献笔记、样本或数据清单、方法试验与失败记录、已确认的选择及方案、已知资源约束。随当前判断注明来源、过去的对象与条件、结果及已知原因，再说明当前的相似与差异、可支持什么、仍需核实什么；原因未明时保留未知。只重查可能变化且会影响当前判断的关键条件，无需重新审阅全部历史或建立额外的经验管理系统。

过去流程跑通只能支持相应条件下的技术可执行性，不能证明当前设计足以回答问题；过去失败也需判断原因是否仍适用。未经确认的协作意向不能计为可用资源，人的投入意愿也不改变资源或证据状态。

## 1. 拆开当前困惑

- **观察**：发生了什么，来自用户经验、数据还是文献，有多稳定？
- **概念与测量**：所用术语指什么，测量实际捕捉了什么？
- **解释与假设**：从观察到解释需要哪些前提，哪些尚待核实？
- **未知与意义**：不理解哪一段，弄清它能增进什么认识？

区分研究主题、知识缺口、问题、假设、目标量与方法。只有方向时先找具体未知；数据异常或测量困难也能生成问题。探索产生的假设注明来源，不追写成事前设定的验证性假设。

Anomaly 要说明与哪个预期不一致，tension 要说明哪些证据或解释冲突；先核实观察和测量是否可靠。Black box 是暂定的未知边界：已知哪些现象或关系，尚不理解哪一段。“机制不明”本身不足以说明价值；描述和测量问题无需先制造异常。

## 2. 从已有认识找到值得追问的未知

领域背景、发展、共识和前沿的检索与判定见 [证据编排](evidence-orchestration.md)。根据当前线索选择有用的角度，不必逐项生成候选：

1. **现象与理论矛盾**：原有解释在哪些条件下不足？
2. **多个解释并存**：组成、状态、异质性或测量过程分别能解释什么？
3. **平均值掩盖差异**：分布、亚群、阶段或状态是什么样？
4. **时间、方向或机制未知**：哪种时序或干预观察能推进理解？
5. **适用边界未知**：在其他人群、组织、物种、平台或阶段是否仍出现？
6. **实际决策不确定**：还需要什么信息才能改善选择？

“尚未做过”、换场景或使用新技术可以提示线索，候选仍需说明具体未知和知识增量。先可靠地描述现象也有价值，不必承诺机制或临床应用。问题表述和记录格式使用 Brief，不要求探索初期填全字段。

## 3. 比较解释，选择最小核实步骤

候选问题回答“研究什么”，竞争解释回答“同一现象可能为什么发生”，不要混成一份备选列表。解释性问题先明确模型共同面对的关键观察及承重假设，形成模型时就寻找预测不同之处，使其参与可行性判断。机制可以共存，候选解释不必互斥或穷尽；排除一种不等于证明另一种。没有合理替代模型时先探索，不凑数量。

例如，组织总体表达变化可先考察细胞组成与细胞内状态各能解释多少。若同类细胞内部仍有稳定变化，组成解释可能不足；不能只因组成解释较简单就宣布它成立。

描述性问题先检查现象能否稳定测得、如何分布，以及测量过程能否产生该现象。每项核实说明它减少什么不确定性，以及支持、阴性或无法区分的结果分别会怎样改变下一步。简化时保留可靠测量、独立重复和识别所必需的条件。

科学问题说明想知道什么；entry point 说明现在从哪里进入、取得什么观察或比较、怎样使认识前进一步。可行性包括结果是否有解释或辨别能力，不能只看分析能否跑通。Why now 可以来自已有数据中的有效比较、测量改进、设计、技术或扰动条件，不要求新技术；入口也可能需先做小规模核实才能建立。

每个候选入口说明所回答的局部未知、必要数据与条件、适用的观察或检验、不同结果怎样更新理解，以及仍不能回答什么。未核实资源标为待核实；“可解决”指能在约束内取得可解释进展，不承诺解完整个大问题或得到阳性结果。

## 4. 按研究目标细化设计

准备投入时明确对象、场景、时间、独立单位、目标量及适用的比较与测量边界。目标量可以是效应，也可以是比例、分布或变化模式；描述性研究无需硬套暴露—干预句式。

| 主要目标 | 问题表达 | 设计时关注 |
| --- | --- | --- |
| 描述 | 发生了什么，如何分布或变化 | 抽样、测量质量、重复性和不确定性 |
| 关联 | 哪些因素共同变化 | 比较、混杂、单位与时间；关系不自动说明方向 |
| 预测 | 能否预测未见个体 | 目标人群、数据泄漏、校准、判别及适用范围 |
| 因果 | 改变暴露是否改变结局 | 干预或明确的识别假设 |
| 机制 | 现象通过什么过程产生 | 区分性预测，按需安排时序、扰动或救援 |
| 转化 | 能否改善实际决策或结局 | 使用者、增量价值、净获益及实施条件 |

不同目标可形成后续问题，一项研究不必完成全部层级。单细胞研究需区分供体与细胞：疾病分组通常在供体层面，同一供体的细胞不能当作独立生物学重复。聚类标签和整合表示应结合测量与生物学依据解释。

## 5. 依据成熟程度判断下一步

| 当前情况 | 下一步 |
| --- | --- |
| 尚未想清楚 | 回到现象、概念或研究者关注点 |
| 尚未核实 | 定向检索、检查数据或小规模观察 |
| 已知路径不可行 | 说明资源或设计冲突与替代路径，由研究者决定调整或搁置 |

准备投入时检查目标与测量、独立单位与抽样、推断与设计、资源可达性及主要偏差的处理路径。假设检验需说明哪些结果能削弱假设；描述研究关注描述目标、测量与重复性，不强求竞争机制。

在一致的时间与投入尺度上，以研究者表达的 interest 和有条件依据的 feasibility 为两轴比较候选；知识增量用于帮助人判断兴趣，不替人赋值。若 A 在两轴均不差于 B 且至少一轴更好，才构成支配；互有优势时保留取舍交给人。评估不确定时先核实关键前提，不静默淘汰。Pareto 不产生唯一最优选择；除非人明确要求并提供权重，不计算总分。转到项目或长期方向的选择时重看对应条件，不直接沿用一次核实的排序。

只补充会改变当前选择的维度。转化是目标时再检查使用者、决策、预期获益和实施条件；基础问题无需补写临床故事。入口受阻可以建议换比较、核实资源或暂时搁置，原始困惑仍可保留，由研究者决定重要转向。

问题可在任一轮修订。若 pilot 后改变假设、分组或结局，标记其探索来源；后续验证说明新资料或未用于形成假设的资料及预先确定的检验，不把同一结果再次分析称为独立验证，也不机械要求小样本切分。
